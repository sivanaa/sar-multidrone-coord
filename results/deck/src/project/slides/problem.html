The problem

A few drones, a flooded area, people to find

Search

Cover the area quickly, without two drones searching the same ground.

Assign

Decide which drone goes to each person found, so everyone is reached soon.

Stay apart

Never let two drones come closer than 1.5 m.

No central controller. Each drone decides from what it hears from the others, and messages can be lost.

Three jobs at once: search, assignment, safety. The hard constraint is that there is no ground station deciding for the fleet. Each drone runs the same code and only knows what reaches it over the radio, and in a disaster area messages get lost. Everything that follows is about doing these three jobs well under that constraint.
